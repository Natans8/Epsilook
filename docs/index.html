Epsilook

Find spells by how they look and sound — a companion for Epsilon WoW

Help

The basics

  • Plain words search names, models, sounds, animations and effects at once, matching any part of a name, in any order.
  • "quoted words" are an exact phrase.
  • Results are ranked by relevance until you sort by a column.
  • finds cfx_mage_fireball_impact.m2
  • Epsilon commands paste straight in

Tags

  • A tag searches one column: name: model: sound: anim: fx: mech: id:. Type the prefix or click a field button.
  • Every tag must match, and words inside one tag must match the same file or effect.
  • A − prefix excludes instead.
  • one model that is both
  • two different models
  • either one
  • novas that deal no damage

Either / or

| means either alternative will do — in any field, with or without spaces around it. Between numbers a comma does the same.

  • beams or dissolves
  • several spells at once

A word, then what it takes

Some words take a value after them: the one word that follows, always. The search bar draws the word and its value joined together, so you can see exactly where the value ends.

  • where on the model it plays
  • which body region moves — quote a value that has a space in it
  • vehicles with 3+ seats
  • more than four models — count works in every column

Anything past that one word is an ordinary search word again, so boneset head kneel is the head region and a kneel animation. To give a value more than one word, put it in quotes: attach "right hand".

Category words

Each column groups its contents under words you can search by. They autocomplete inside a tag and combine with file words in the same tag.

  • also attached ground trail barrage display item mount equipped
  • whose projectile is an arrow
  • also dissolve glow ghost tint desaturate transparency freeze camo screen shapeshift morph summon object scale
  • also seat invis detect keybind — the things a spell does that you cannot see
  • also passenger
  • a colour, by hex or by name

Who it plays on

The icons on each pill say who the content plays on. They search like category words in any marked column. caster, target, target but never caster, where the spell lands. Unmarked rows carry no target type in the game data.

  • fire model on the caster
  • plays on caster and target

The search bar

  • The bar colours what the search understands, and explains it on hover. Anything it does not colour is an ordinary text search.
  • Enter, Tab or → close the tag you're typing; ← at its start closes it the other way. In an empty gap the arrows and Backspace step into the neighbouring tag.
  • Click a tag's text to edit it, its × to remove it, its field label to flip it between include and exclude.
  • Ctrl+A, drag or Shift+←/→ select across tags; Ctrl+C copies the selection as query text. Ctrl+Z undoes any bar edit.

Results, filters, sharing

  • Click any pill to search for it; Shift-click excludes it. ⧉ copies an ID; .lo, /, .mod and the Commands buttons copy Epsilon commands — Shift-click wraps the copy in `backticks`.
  • ▶ plays a sound. Hovering a texture pill previews it; hovering a colour swatch shows the colour with its hex.
  • Filter buttons cycle any → only with → only without. Sorting cycles ▲, ▼, back to relevance; the multi-value columns sort by number of entries.
  • Hiding a column also leaves it out of plain-word search and exports.
  • The URL always holds your search: 🔗 Share copies it. Add &export=json or &export=csv to download it instead.
